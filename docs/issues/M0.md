**Title:** M0 - Foundation

**Goal:** A monorepo foundation that runs from a fresh clone with one command and has green CI.

**In scope:**
- Folder layout: apps/web, apps/api, packages/imaging, packages/ui-kit, workers, infra, benchmarks, tests, docs
- docker-compose with PostgreSQL, Redis and MinIO (S3-compatible storage)
- FastAPI service with a health endpoint and OpenAPI docs
- React + TypeScript + Vite shell
- Auth skeleton, project and asset models, job state machine (queued, processing, review_required, completed, failed, cancelled)
- Tool-audit page listing every planned tool with status "not built"
- CI in GitHub Actions: lint, type check, unit tests, build

**Out of scope:** everything else, including any imaging, colour or AI tools.

**Acceptance tests:**
1. A fresh clone starts the whole stack with one documented command.
2. CI is green on the pull request.
3. A test calls the health endpoint and passes.
4. A test moves a job through queued, processing and completed, and rejects an invalid transition.
5. The audit page shows no tool as "working".
6. No secrets are present in the repository.

**Benchmark metrics to report:** none for this milestone.

**I will provide:** nothing yet; no credentials are needed.

**Definition of done:** all acceptance tests pass in CI; the report from AGENTS.md is posted in the pull request.
